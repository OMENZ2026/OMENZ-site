HOW TO READ TIM

  • Known answers, every 6h: we run the tool on inputs where the right answer is known (a fake phone number, an expired certificate, a made-up package) and alert ourselves if it ever answers wrong.
  • Frozen holdout: the tool passed a test set locked before the release, the strictest bar we use.
  • Requests vs paid: requests are outside calls, most of them free price checks by agents, directories and crawlers. Paid counts completed paid calls, including marketplace verification buys (directories that pay once to confirm a tool works). Our own tests are excluded. New tools start at zero and earn their record.
  • Raw data, free: /api/tollbooth/v1/track-record (JSON for agents). Try any tool free first in AYNE.

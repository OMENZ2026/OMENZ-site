3Pay automatically (Python)

The official x402 client signs a USDC payment when it gets a 402 and retries. Tested end to end against OMENZ.

pip install "x402[requests,evm]" eth-account

from eth_account import Account
from x402 import x402ClientSync
from x402.mechanisms.evm.exact import ExactEvmScheme
from x402.http.clients.requests import x402_requests

client = x402ClientSync().register("eip155:8453", ExactEvmScheme(Account.from_key(YOUR_WALLET_KEY)))
s = x402_requests(client)   # pays when it gets a 402
r = s.get("https://www.omenz.org/api/tollbooth/v1/site-check?url=https://example.com")
print(r.json())

Your wallet needs a little USDC on Base. Keep your key in your own process; OMENZ never sees it.
